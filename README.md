# .dockerignore
.dockerignore tailored for djazz applications, For more help, visit the .dockerignore file reference guide at https://docs.docker.com/go/build-context-dockerignore/


## Basic .dockerignore syntax

- Leading and trailing slashes in ignore patterns are disregarded. 
- `#` is used to add comments to the .dockerignore file.
- `!` is used to negate the pattern.
